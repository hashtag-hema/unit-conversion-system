# Unit Conversion System

A simple Python-based Unit Conversion System that allows users to convert different units through a menu-driven program.

I created this project as part of my Python fundamentals learning to understand how functions, conditional statements, operators and user input work together in a program.

## Features

The program supports four types of conversions:

- **Length:** Kilometers to Miles and Miles to Kilometers
- **Weight:** Kilograms to Grams and Grams to Kilograms
- **Temperature:** Celsius to Fahrenheit and Fahrenheit to Celsius
- **Time:** Hours to Minutes and Minutes to Hours

## Concepts Used

- Python functions (`def`)
- User input (`input()`)
- Variables and data types
- Conditional statements (`if-elif-else`)
- Arithmetic operators
- Return statements
- Exception handling (`try-except`)

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python unit_conversion.py
```

5. Select a conversion category.
6. Choose the conversion direction and enter the value.

The program will display the converted result, rounded to two decimal places.

## Input Validation

The program also handles invalid menu choices and non-numeric inputs to avoid errors during execution.
